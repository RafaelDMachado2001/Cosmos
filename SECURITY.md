# Security policy

If you find a security issue in RDM Labs · Cosmos (the site at
cosmos.rdmlabs.com.br, the API at api.rdmlabs.com.br, or this repository),
please report it privately rather than opening a public issue:

- [Report a vulnerability](https://github.com/RafaelDMachado2001/Cosmos/security/advisories/new)
  through GitHub's private reporting, or
- send a message on [LinkedIn](https://www.linkedin.com/in/rafael-dorneles-machado-8478b3172).

Include what you found, how to reproduce it, and what an attacker could do with
it. Reports in Portuguese or English are both fine. I'll reply as soon as I can
and keep you posted until it's fixed.

Only the latest version on `main`, which is what runs in production, is
supported.
